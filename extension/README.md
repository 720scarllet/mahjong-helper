# 雀魂网页接入扩展

此扩展用于将 Chrome / Edge 中的官方雀魂网页消息发送到本机悬浮助手，支持三人和四人对局。接收的消息不修改游戏操作；不自动打牌。网页版也可以直接用助手的内置游戏窗口，此时无需安装扩展。

## 安装

1. 打开悬浮助手，将数据来源切换到“浏览器扩展”。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本 `extension` 文件夹，也就是包含 `manifest.json` 的文件夹。
4. 在助手中点击“复制配对码”，点击浏览器工具栏中的“雀魂悬浮助手”扩展，将配对码粘贴并保存。
5. 刷新雀魂游戏页面，重新登录并进入对局。安装扩展前已开始的连接不会被补采集；新局开始后数据才完整。

助手每次重新启动都会生成新密钥，需要重新复制并保存。扩展重新加载或更新后也需要刷新游戏页面。为避免浏览器后台页面冻结，请保持游戏所在标签页处于活动状态。

## 支持的网址

- 国际中文服：`https://game.maj-soul.com/1/`、`https://game.maj-soul.net/1/`
- 英文服：`https://mahjongsoul.game.yo-star.com/`
- 日文服：`https://game.mahjongsoul.com/`

只在以上官方域名注入消息监听。密钥保存在扩展的本机存储中，不传给游戏网页、不启用浏览器账户同步。二进制消息只发往 `http://127.0.0.1:19221/frame`，没有外部上传地址。卸载扩展会删除其存储。

## 连接状态

扩展角标 `ON` 表示最近有消息成功送达助手；`!` 表示连接失败。它表示消息桥接状态，并不代表已进入对局或所有消息都成功解析。扩展弹出面板显示错误原因，助手中的接收消息数和协议状态用于确认对局解析。

- “无法连接悬浮窗”：确认助手正在运行；检查本机端口 19221 是否被其他程序占用。
- “密钥失效”：从当前运行的助手重新复制密钥并保存，刷新游戏页面。
- 已连接但没有手牌：确认助手选中了浏览器扩展来源，重新登录后进入新局；必要时在助手中更新对应服务器的协议。
- 切换账号、服务器或从牌谱返回实战后信息不完整：刷新游戏页面后开始新局。

本扩展不用于 Steam / Windows 客户端；客户端应使用助手提供的客户端接入选项。浏览器需要支持 Manifest V3 的 MAIN world 内容脚本（Chrome 111 及更新版本，或对应新版 Edge）。

## 本地验证

在本文件夹运行 `node --test tests/*.test.cjs`，检查 WebSocket 构造和原始发送行为、二进制快照、Blob 顺序、关闭消息、接入权限与密钥隔离。实际对局连接仍需在官方网页上验证。
